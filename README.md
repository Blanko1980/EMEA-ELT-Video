# In Full Confidence

A 2:20 animated film for the internal We. conference (screening: October 7, 2026), generated entirely as code with [Remotion](https://www.remotion.dev/). It tells the AI revolution through one chat history, from a sceptical Teams message in December 2022 to directing AI agents in 2026.

- **Final film:** `out/in-full-confidence.mp4` (1920 × 1080, 30 fps, H.264), plus `out/in-full-confidence-muted.mp4` as the venue fallback
- **Web player:** `docs/index.html` (build with `npm run player:build`; serve `/docs` via GitHub Pages)

## Commands

| Command | What it does |
| --- | --- |
| `npm install` | Install dependencies |
| `npx remotion studio` | Live preview with timeline scrubbing |
| `npm run render` | Final MP4 → `out/in-full-confidence.mp4` |
| `npm run render:muted` | Silent MP4 → `out/in-full-confidence-muted.mp4` |
| `npm run audio` | Re-synthesise music + SFX in code → `public/audio/music.mp3`, `sfx.mp3` |
| `npm run voice` | Re-generate the two voice lines with ElevenLabs (needs `ELEVENLABS_API_KEY`) |
| `npm run map` | Rebuild the dot-matrix world map from Natural Earth data |
| `npm run player:build` | Build the web player into `docs/` |
| `npm run typecheck` | TypeScript check |

## Where things live

```
src/
  data/          every date, quote, label and timecode (edit facts here, not in components)
    chat.json        cold open + finale chat, outro lines, screening date
    world.json       THE WORLD lane events (with fact-check status and sources)
    personal.json    DANIEL lane events, people groups, crescendo
    quotes.json      the six verbatim quotes with sources
    acts.json        act timings, year subtitles, timeline speed, music tempo
    transition.json  timings for the 0:27–0:35 transition
    finale.json      timings for the finale and logo reveal
  theme.ts       We. brand tokens (palette, Libre Baskerville + Source Sans, layout, easing)
  config.ts      audio switches (music, SFX, voice mode) and ElevenLabs voice IDs
  Film.tsx       sequences all acts; Root.tsx registers "InFullConfidence"
  acts/          Act0ColdOpen, Transition, Act1_2023 … Act4_2026, Finale
  components/    chat, timeline, year/user counters, lane events, quote cards, visuals
scripts/         generate-audio.ts, generate-voice.ts, build-map.ts, stills.ts
public/          fonts, audio, official We. logo artwork
```

## Correcting a fact

Change the value in `src/data/*.json`, then preview in `npx remotion studio`. Timing changes in the data also move the matching sound effects: run `npm run audio` afterwards.

## Voice moment (Dec 20, 2024)
